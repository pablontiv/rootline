# E04: Developer Experience — Advanced Features

**Estado**: In Progress
**Metrica de exito**: Rootline soporta dependency graph, sequence autonumbering, structural validation, y proposal-based fix engine
**Timeline**: 2026-Q1 — en curso

## Intencion

Extender rootline con capacidades avanzadas que mejoran la experiencia del desarrollador: dependency graph entre documentos, autonumeración de secuencias en .stem, validación estructural de directorios, cobertura de edge cases, y un motor de propuestas para el comando fix.

## Features

| Feature | Descripcion |
|---------|-------------|
| [F04 Derivation Engine](F04-derivation-engine/README.md) | Motor de evaluación de expresiones y derivación |
| [F05 Dependency Graph](F05-dependency-graph/README.md) | Grafo de dependencias entre documentos |
| [F06 Rootline Skill Backend](F06-rootline-skill-backend/README.md) | Integración rootline CLI con skills |
| [F07 Sequence Autonumbering](F07-sequence-autonumbering/README.md) | Secuencias auto-incrementales en .stem |
